# Make input vector unit length, i.e. norm == 1

Make input vector unit length, i.e. norm == 1

## Usage

``` r
unit(vector)
```

## Arguments

- vector:

  a vector

## Value

a unit length vector

## See also

Other helpers:
[`deg()`](https://nvctr.ansperformance.eu/reference/deg.md),
[`rad()`](https://nvctr.ansperformance.eu/reference/rad.md)

## Examples

``` r
unit(c(1,2,3))
#> [1] 0.2672612 0.5345225 0.8017837
```
