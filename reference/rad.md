# Convert angle in degrees to radians.

Convert angle in degrees to radians.

## Usage

``` r
rad(degrees)
```

## Arguments

- degrees:

  angle in degrees.

## Value

angle in radians

## See also

[`deg`](https://nvctr.ansperformance.eu/reference/deg.md).

Other helpers:
[`deg()`](https://nvctr.ansperformance.eu/reference/deg.md),
[`unit()`](https://nvctr.ansperformance.eu/reference/unit.md)

## Examples

``` r
rad(30)
#> [1] 0.5235988
```
