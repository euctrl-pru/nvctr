# Convert angle in radians to degrees

Convert angle in radians to degrees

## Usage

``` r
deg(radians)
```

## Arguments

- radians:

  angle in radians.

## Value

angle in degrees.

## See also

[`rad`](https://nvctr.ansperformance.eu/reference/rad.md).

Other helpers:
[`rad()`](https://nvctr.ansperformance.eu/reference/rad.md),

## Examples

``` r
deg(pi/2)
#> [1] 90
```
