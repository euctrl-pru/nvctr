# nvctr: non-singular geographical position calculations

nvctr provides functions to calculate geographical positions for both
the ellipsoidal and spherical Earth models.

## References

Kenneth Gade [A Nonsingular Horizontal Position
Representation](https://www.navlab.net/Publications/A_Nonsingular_Horizontal_Position_Representation.pdf).
*The Journal of Navigation*, Volume 63, Issue 03, pp 395-417, July 2010.
